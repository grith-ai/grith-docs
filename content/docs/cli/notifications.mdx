```
grith notifications status | channels | test <CHANNEL>
```

All three subcommands print the same message and exit `0`. `test` still requires a
`<CHANNEL>` argument - without one it exits `2` with a usage error, before reaching
the message.

<Terminal>
{`$ grith notifications status
Notifications are coming soon.

Get alerts — and approve or deny — from Telegram, Slack and more,
set up from your dashboard with no local configuration. It's on the
way; this command will light up when it arrives.`}
</Terminal>

The `--help` descriptions for `status`, `channels` and `test` describe the intended
feature, not what the command does today.

See [Notifications](/docs/pro/notifications).
