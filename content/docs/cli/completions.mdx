```
grith completions <SHELL>
```

Print a shell tab-completion script for `grith` to stdout. Supported shells are
`bash`, `zsh`, `fish`, `elvish`, and `powershell`. The script is written to stdout
only — nothing is installed — so you pipe or redirect it wherever your shell loads
completions from.

## Arguments

| Argument | Required | What it is |
| --- | --- | --- |
| `<SHELL>` | yes | Target shell: `bash`, `zsh`, `fish`, `elvish`, or `powershell`. |

## Examples

Load bash completions for the current session:

```
source <(grith completions bash)
```

Install them permanently (bash):

```
grith completions bash > ~/.local/share/bash-completion/completions/grith
```

zsh — write to a directory on your `$fpath`:

```
grith completions zsh > ~/.zfunc/_grith
```

fish:

```
grith completions fish > ~/.config/fish/completions/grith.fish
```

## Notes

- The command emits the script and exits; it doesn't touch your config or start the
  daemon, so it works regardless of config state.
- Regenerate the script after upgrading grith to pick up new commands and flags.
